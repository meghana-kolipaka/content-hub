How a Website Loads in Under a Second

By Arjun Nair · 2026-10-05 · Web

From typing a URL to seeing a page: DNS, servers, HTML, CSS and JavaScript explained step by step.

When you enter a URL, the browser finds the server through DNS and requests the page.

The server returns HTML. The browser then loads CSS for styling and JavaScript for behavior.

Small images and clean markup help pages load faster. See Writing Accessible Web Content for related best practices.
